# Supervised Learning

Supervised learning uses examples with known answers (labels or target values)
to train a model. After training, the model can make predictions for new inputs.

## Algorithms

- [Linear regression](./linear-regression/README.md): predict a numeric value
  with a linear relationship. The folder demonstrates gradient descent from
  scratch and the scikit-learn implementation.

Add future supervised-learning algorithms as separate folders alongside
`linear-regression`.
